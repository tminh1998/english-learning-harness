1transpile

/trænˈspaɪl/ · verb
IT

dịch code sang bản khác mà vẫn là codeTS ra JS, JS bản mới ra JS bản cũ — đầu ra vẫn là source code đọc được, chứ không ra file máy chạy

ENTo transpile code is to turn source code written in one language or language version into source code in another, so an older runtime or browser can run it. → Transpile code là đổi code nguồn viết bằng một ngôn ngữ hoặc một bản ngôn ngữ thành code nguồn của một bản khác, để runtime cũ hay trình duyệt cũ chạy được.

GHI CHÚKhác compile ở chỗ đầu ra: compile ra bytecode hay file máy chạy, transpile ra code nguồn khác. Dev Việt nói thẳng "transpile", "build qua Babel" — không ai nói "biên dịch chéo". Gặp ở Babel, tsc, SWC, esbuild.

Ví dụ
  • We transpile the TypeScript down to ES2017 so the two oldest Android clients stay backward compatible. → Bọn mình transpile TypeScript xuống ES2017 để hai con Android cũ nhất vẫn chạy được với bản mới.
  • Babel was the culprit — we were transpiling every file twice, once for the tests and once for the bundle. → Thủ phạm là Babel — bọn mình transpile mỗi file tới hai lần, một lần cho test, một lần cho bundle.
Collocationtranspile TS to JS · transpile down to ES5 · a transpile step · transpiled output
BẫyGiới từ là to hoặc down to, không phải into a — viết transpile to ES2017. Và đây là động từ: đừng viết make a transpile of the code, muốn dùng danh từ thì a transpile step. Trọng âm vần hai: /trænˈspaɪl/.
Họ từtranspiles, transpiled, transpiling, transpiler, transpilation, transpiled bundle

2garbage collection

/ˈɡɑː.bɪdʒ kəˌlek.ʃən/ · noun (không đếm được)
IT

tự thu hồi bộ nhớ không còn ai dùngruntime tự đi tìm chỗ nào chương trình không với tới được nữa rồi lấy lại — mình không gọi free() như C; đổi lại là thỉnh thoảng nó dừng chương trình một nhịp để dọn

ENGarbage collection is the runtime's own job of finding memory that no part of the program can reach any more and taking it back, so you never free it by hand. → Garbage collection là việc runtime tự đi tìm những vùng bộ nhớ mà không chỗ nào trong chương trình với tới được nữa rồi lấy lại, nên mình không bao giờ phải tự tay giải phóng.

GHI CHÚNói tắt là GC, và cái dừng một nhịp đó gọi là GC pause / stop-the-world. Đừng lẫn với memory leak: leak là mình vẫn còn giữ tham chiếu nên GC không dám dọn — GC chạy đúng, lỗi ở code.

Ví dụ
  • Those two-second freezes in the dashboard are garbage collection pauses, not a bottleneck in the query. → Mấy cú treo hai giây trên dashboard là do GC dừng dọn bộ nhớ, chứ không phải chỗ nghẽn ở câu query.
  • Garbage collection can't save us here — the cache keeps a reference to every event we ingest, so the heap only grows. → GC cũng chẳng cứu được chỗ này — cache còn giữ tham chiếu tới mọi event mình ingest, nên heap chỉ phình lên chứ không giảm.
Collocationa garbage collection pause · trigger a garbage collection cycle · the garbage collector · GC pressure
BẫyKhông đếm được: đừng viết a garbage collection trơ trọi — muốn đếm thì thêm danh từ, a garbage collection pause. Và garbage đọc /ˈɡɑː.bɪdʒ/, trọng âm vần đầu, đuôi là /-bɪdʒ/ chứ không phải "-bây".
Họ từgarbage collector, garbage-collected, GC, GC pause, collect garbage, generational GC

Bài tập

5 câu về từ vựng của buổi. Làm xong rồi mới mở đáp án.

  1. Điền từ: "Those two-second freezes are ________ pauses, not a slow query."
  2. Sửa lỗi: "Just to reiterate about the March date, it does not move."
  3. Dịch Việt-Anh: "Khâu rà soát bảo mật thì không thương lượng được ạ."
  4. Chọn collocation đúng: (a) transpile the TypeScript down to ES2017 · (b) transpile the TypeScript into a ES2017 · (c) make a transpile of the TypeScript
  5. Chọn từ đúng: Chưa uống cà phê, ai nói gì cũng gắt — (a) grumpy · (b) fed up · (c) awkward
Đáp án
  1. garbage collection — garbage collection pauses. Không đếm được nên không có a garbage collection trơ trọi; muốn đếm thì thêm danh từ như pause / cycle.
  2. "Just to reiterate, the March date does not move." — bỏ about. reiterate đi thẳng với tân ngữ hoặc với that…, không có giới từ.
  3. "The security review is non-negotiable." — nhớ gạch nối. Muốn nhẹ hơn thì we don't have much room on the security review.
  4. (a) transpile the TypeScript down to ES2017 — giới từ down to; (b) sai vì into a, (c) sai từ loại: transpile là động từ.
  5. (a) grumpy — fed up là ngán tận cổ vì một chuyện cụ thể, awkward là ngượng/bất tiện, không phải chuyện tâm trạng dễ gắt.
