1latency

/ˈleɪ.tən.si/ · noun
IT

độ trễbấm xong bao lâu mới có kết quả

ENLatency is the delay between asking a system for something and getting the answer back. → Latency là khoảng chờ từ lúc mình hỏi hệ thống một việc cho tới lúc nhận được câu trả lời.

GHI CHÚKhác throughput (chạy được bao nhiêu việc mỗi giây): latency là một request mất bao lâu. Hệ thống throughput cao mà latency vẫn tệ là chuyện thường — nhiều người xếp hàng, mỗi người vẫn phải chờ.

Ví dụ
  • The checkout page has about two seconds of latency on mobile, and that's the biggest pain point our users keep reporting. → Trang checkout trên mobile trễ tầm hai giây, đó là chỗ khách kêu nhiều nhất.
  • We still haven't nailed down where the extra latency comes from — the database or the image service. → Bọn mình vẫn chưa chốt được chỗ trễ thêm nằm ở đâu, database hay service ảnh.
Collocationhigh / low latency · latency spike · reduce latency · network latency · p95 latency
BẫyTrọng âm ở đầu: /ˈleɪ.tən.si/ (LÂY-tơn-si), không phải "la-TEN-cy". high latency = chậm, low latency = nhanh — rất hay nói ngược. Nói chung thì không đếm được; latencies chỉ dùng khi so nhiều con số.
Họ từlatency · latencies · latent · low-latency · high-latency

2stub

/stʌb/ · noun & verb
IT

bản giả tạm, chờ bản thậtđộng từ: stub out something

ENA stub is a fake, minimal version of a function or endpoint that returns something simple so the rest of the code can run before the real thing exists. → Stub là bản giả tối giản của một hàm hay endpoint, trả về đại một thứ đơn giản để phần code còn lại chạy được trong lúc bản thật chưa có.

GHI CHÚGần nghĩa mock nhưng khác chỗ dùng: mock thiên về test (kiểm tra xem có được gọi đúng không), còn stub chỉ cần có cái gì đó trả về để chạy tiếp.

Ví dụ
  • The payment API isn't ready yet, so I'll stub the endpoint and we stay on track for the demo. → API thanh toán chưa xong nên mình viết tạm cái endpoint giả, để buổi demo vẫn kịp tiến độ.
  • Don't leave a stub in production — swap it for the real call before the client signs off. → Đừng để bản giả lọt lên production; thay bằng call thật trước khi khách duyệt.
Collocationstub out an endpoint / a function · a stub implementation · return a stub · stub data
BẫyTrong nghề nói gọn: "it's just a stub" — không cần thêm chữ "function" hay "file". Đừng lẫn với stump (gốc cây) hay stab (đâm). Chia thường: stubbed, stubbing.
Họ từstubs · stubbed · stubbing · stub out · stub data · a stub implementation

5 câu về từ vựng của buổi. Làm xong rồi mới mở đáp án.

  1. Điền từ: "The API is fine on desktop, but mobile users see two seconds of ______ on every search."
  2. Điền từ: "The real endpoint isn't ready — I'll write a ______ that returns three fake rows."
  3. Sửa lỗi: "I have to do some errands this afternoon, so let's start at four."
  4. Dịch Việt–Anh: "Mình ghi tạm sáng thứ Sáu cho buổi review nhé, chưa chốt đâu."
