# lessons/ — Bài học từng ngày

Gom theo **tuần ISO**: `lessons/YYYY-Www/YYYY-MM-DD.md`. Tuần là đơn vị của bài
kiểm tra, nên `/kiem-tra` chỉ cần đọc trọn một thư mục tuần.

Mỗi file = 1 buổi = 5 từ mới + mẩu đọc + bài tập (đáp án bọc `<details>`).
Học thêm buổi hai trong cùng ngày → `YYYY-MM-DD-2.md`.

Khuôn: [`../_templates/lesson.md`](../_templates/lesson.md)
