1lockfile

/ˈlɒk.faɪl/ · noun (đếm được)
IT

file ghim đúng version của từng dependencycài lại ở máy khác hay trên CI vẫn ra đúng bộ package đó, không phải bản mới nhất khớp khoảng version

ENA generated file that records the exact version of every package an install produced, so the same install can be repeated anywhere. → Một file do máy sinh ra, ghi lại đúng version của từng package mà lần cài đó tạo ra, nhờ vậy cài lại y hệt ở đâu cũng được.

GHI CHÚpackage.json nói "chấp nhận version nào", lockfile nói "lần đó thật ra cài version nào". Luôn commit vào repo — không commit thì mỗi máy một bộ package khác nhau. Gặp merge conflict trong lockfile thì đừng sửa tay: xoá đi, cài lại, commit bản mới.

Ví dụ
  • Don't hand-edit the lockfile when you hit a merge conflict — regenerate it, then check that no transitive dependency jumped a major version. → Gặp merge conflict trong lockfile thì đừng sửa tay — xoá đi cài lại, xong soi xem có dependency nào cài kèm nhảy hẳn một major version không.
  • (email khách) We keep the lockfile in the repo, so the build you sign off on is byte-for-byte the one we tested. → Bên em giữ lockfile ngay trong repo, nên bản build anh/chị duyệt chính thức đúng từng byte với bản bên em đã test ạ.
Collocationcommit the lockfile · regenerate / update the lockfile · a stale lockfile · a lockfile conflict · npm ci reads the lockfile
BẫyViết liền lockfile hay tách lock file đều gặp, nhưng tên file thật thì phải đúng chữ của tool: package-lock.json, yarn.lock, pnpm-lock.yaml. Đừng lẫn với lock (khoá một dòng trong database) hay deadlock — cùng chữ lock nhưng chẳng liên quan gì nhau.
Họ từlockfiles, lock file, lock-file, lockfile conflict, locked versions, pin a version

2fixture

/ˈfɪks.tʃər/ · noun (đếm được)
IT

dữ liệu dựng sẵn cho testtạo trước mấy bản ghi mẫu, chạy test xong thì dọn đi — nên test nào cũng khởi đầu từ cùng một chỗ

ENA set of data and state prepared before a test runs, so every run of that test starts from exactly the same place. → Một bộ dữ liệu và trạng thái được dựng sẵn trước khi test chạy, nhờ vậy lần nào chạy test đó cũng khởi đầu từ đúng một chỗ.

GHI CHÚKhác stub: fixture là dữ liệu test đọc vào, stub là cái giả lời gọi đi ra ngoài. Ngoài phòng test, fixture nghĩa đời thường là đồ gắn cố định trong nhà (đèn, vòi nước), bên Anh còn là lịch đấu bóng — cùng một chữ, ba nghĩa, nhìn ngữ cảnh mà đoán.

Ví dụ
  • Each test loads the same fixture and then uses a stub for the payment call, so nothing ever leaves the machine. → Mỗi test nạp cùng một bộ dữ liệu dựng sẵn rồi cắm một bản giả tạm cho lời gọi thanh toán, nên chẳng có gì chạy ra ngoài máy.
  • Three suites were each seeding their own users, so I pulled it all into one shared fixture — that alone killed two flaky tests. → Ba bộ test đứa nào cũng tự tạo user riêng, nên mình gom hết vào một bộ dữ liệu dùng chung — chỉ vậy thôi là hết hai cái test chập chờn.
Collocationa test fixture · load / set up a fixture · tear down the fixture · fixture data · a shared fixture
BẫyĐọc /ˈfɪks.tʃər/ — "fích-chơ", không đọc rời ra thành "fik-tu-rờ". Đếm được: a fixture / fixtures. Và đừng gọi mock hay stub là fixture: fixture là dữ liệu nằm sẵn, mock/stub là thứ đóng thế một lời gọi.
Họ từfixtures, test fixture, fixture data, fixture file, fix, fixed

Bài tập

5 câu về từ vựng của buổi. Làm xong rồi mới mở đáp án.

  1. Điền từ: "Every machine installed a slightly different minor version until we committed the ______."
  2. Sửa lỗi: "Can you add me in the shortlist? I'm the main contact point for this project."
  3. Dịch Việt-Anh: "Ăn không hết thì mình xin cái hộp mang về đi." (dùng doggy bag)
  4. Chọn collocation: "Before each test we ______ the fixture." — (a) load (b) download (c) install
  5. Chọn từ đúng: "A ______ gives the test its data; a ______ fakes the call that goes out." — (a) fixture / stub (b) stub / fixture (c) doggy bag / fixture
Đáp án
  1. lockfile — commit the lockfile là cụm hay đi với nó nhất; package.json chỉ nói chấp nhận khoảng version nào, lockfile mới ghim đúng version đã cài.
  2. "Can you add me to the shortlist? I'm the main point of contact for this project." — hai lỗi: giới từ là on/to the shortlist chứ không phải "in", và thứ tự cố định là point of contact, không đảo thành "contact point".
  3. "Can we get a doggy bag?" hoặc "Let's ask for a doggy bag." — ask for a doggy bag / get a doggy bag; bên Mỹ nói can you box this up? cũng được.
  4. (a) load — load a fixture (hoặc set up a fixture). download là tải từ mạng về, install là cài package — cả hai đều lạc chỗ ở đây.
  5. (a) fixture / stub — fixture là dữ liệu test đọc vào, stub (đã học 2026-09-05) là cái đóng thế một lời gọi đi ra ngoài.
