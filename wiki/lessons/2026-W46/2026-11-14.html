1lint

/lɪnt/ · verb (cũng là noun; công cụ gọi là linter)
IT

rà code theo quy ước, báo chỗ viết saimáy đọc code chứ không chạy — bắt biến khai mà không dùng, thiếu dấu, chỗ viết lệch quy ước của team

ENTo lint code is to run a tool over it that flags style slips, unused variables and likely mistakes before the code is ever run. → Lint code là chạy một công cụ rà qua code, nó chỉ ra chỗ viết lệch quy ước, biến khai mà không dùng và những lỗi dễ xảy ra, trước khi code được chạy lần nào.

GHI CHÚKhác smoke test: lint không chạy code, chỉ đọc. Khác review: lint để máy bắt mấy lỗi vụn vặt, người review dành sức cho phần logic. Công cụ gọi là linter; lint nghĩa gốc là xơ vải đọng trong máy sấy.

Ví dụ
  • The linter nitpicks the small stuff, so review time goes to the logic instead. → Con linter bắt lỗi vụn vặt hộ rồi, nên giờ review dành cho phần logic.
  • Every PR runs lint first, then a smoke test — if lint fails nothing else even starts. → Mỗi PR chạy lint trước, rồi mới test nhanh một lượt — lint đỏ là mọi thứ phía sau không thèm chạy.
Collocationlint the code · run the linter · linting errors · fix the lint warnings · lint rule · lint-staged
Bẫylint dùng được như động từ (lint the file) — đừng nói "do lint", nói run lint hoặc run the linter. Đọc /lɪnt/ ngắn, không phải /laɪnt/.
Họ từlinter, linting, linted, lint rule, lint-staged, unlinted

2minify

/ˈmɪn.ɪ.faɪ/ · verb
IT

rút gọn code cho file nhẹ đibỏ khoảng trắng, bỏ comment, đổi tên biến thành một chữ — code chạy y nguyên, file nhỏ đi mấy lần

ENTo minify a file is to strip out everything a machine doesn't need — spaces, comments, long names — so it downloads faster while behaving exactly the same. → Minify một file là bỏ hết những thứ máy không cần — khoảng trắng, comment, tên dài — cho nó tải về nhanh hơn mà chạy vẫn y như cũ.

GHI CHÚKhác tree shaking là bỏ hẳn code không ai dùng — minify giữ nguyên code, chỉ viết lại cho ngắn. Bản đã minify thì stack trace đọc không ra gì, nên phải đẩy source map lên chỗ nhận lỗi. Hay đi cặp với bundle và gzip.

Ví dụ
  • Minifying the vendor bundle was the low-hanging fruit — one build flag, and the page got 400 kilobytes lighter. → Minify cái vendor bundle là việc dễ mà ăn ngay — bật một flag lúc build, trang nhẹ đi 400 kilobyte.
  • Minified stack traces are impossible to triage, so ship the source maps to the error tracker too. → Stack trace của bản đã minify thì không phân loại rồi xếp ưu tiên nổi, nên đẩy luôn source map lên chỗ nhận lỗi.
Collocationminify the bundle · a minified build · minified and gzipped · minify CSS/JS · unminified source
BẫyĐừng nhầm với gzip: gzip là nén lúc truyền, minify là viết lại code cho ngắn — hai việc khác nhau, thường làm cả hai. Trọng âm ở vần đầu /ˈmɪn.ɪ.faɪ/.
Họ từminified, minifying, minifier, minification, unminified

5thrifty

/ˈθrɪf.ti/ · adjective

ENSomeone thrifty is careful with money and gets good value out of it, without being mean about it. → Người thrifty là người cẩn thận với tiền và tiêu sao cho đáng, nhưng không tới mức bủn xỉn.

GHI CHÚKhác stingy (bủn xỉn — chê) và khác broke (cháy ví, hết tiền). Nói về người, về thói quen, hoặc về một lựa chọn: the thrifty option. Nghe hơi cũ một chút nhưng vẫn là lời khen.

Ví dụ
  • She's the most thrifty person I know, but she still picked up the tab for the whole team on her birthday. → Chị ấy là người tiết kiệm nhất mình biết, mà sinh nhật vẫn bao cả bàn cho cả team.
  • Procurement went with the thrifty option, so we're on refurbished machines until the next budget. → Bên thu mua chọn phương án tiết kiệm, nên tới đợt ngân sách tới bọn mình dùng máy tân trang.

Bẫyth là /θ/ (lưỡi chạm nhẹ hai hàng răng), đừng đọc thành /t/ hay /s/. Đừng dùng thrifty để chê — chê thì là stingy, tight-fisted, cheap. Danh từ hay dùng là thrift.
Họ từthrift (n), thriftily, thriftiness, unthrifty, thrift store/shop, spendthrift (ngược nghĩa)

CI giờ chạy lint ở mọi pull request, và lúc build thì rút gọn luôn cái vendor bundle, nên trang sản phẩm nhẹ hơn tháng trước 400 kilobyte — em đã tính phần đó vào dự báo hiệu năng cho Q1. Việc nữa: khoá Web Performance em tự bỏ tiền mua trước, chứng từ em gửi kèm, chị cho hoàn lại trong đợt thanh toán tới nhé. Em biết quý này bên mình đang tiết kiệm, nên em đã lọc lại từ ba khoá còn đúng một khoá rẻ nhất mà vẫn dạy phần bundle size.

Bài tập

5 câu về từ vựng của buổi. Làm xong rồi mới mở đáp án.

  1. Điền từ: CI runs ______ on every pull request, so a missing semicolon never reaches review.
  2. Sửa lỗi: "Please reimburse me the taxi fare — I have the receipt."
  3. Dịch Việt-Anh: "Bản đã minify thì đọc stack trace không ra gì, nên phải đẩy source map lên luôn."
  4. Chọn collocation đúng: (a) revise the forecast · (b) forecast about Q1 · (c) do a forecast of Q1
  5. Chọn từ đúng: Chị ấy khéo tiêu, tháng nào cũng để ra được một khoản — (a) stingy · (b) thrifty · (c) broke
Đáp án
  1. lint — run lint / run the linter; lint đọc code chứ không chạy code nên bắt được lỗi cú pháp trước cả khi build.
  2. "Please reimburse me for the taxi fare" — reimburse sb FOR sth. Bỏ for là lỗi hay gặp nhất với từ này.
  3. "Minified stack traces are unreadable, so ship the source maps too." — minified làm tính từ; đừng dùng compressed ở đây, nén lúc truyền là việc của gzip.
  4. (a) revise the forecast — "sửa lại dự báo". (b) sai giới từ, phải là forecast for Q1; (c) lòng vòng — người bản ngữ nói forecast Q1 hoặc a forecast for Q1.
  5. (b) thrifty — là lời khen, khéo tiêu. stingy là bủn xỉn (chê), broke là hết tiền.
