# MEMORY — Rule đã học về cách học của learner

> Index, mỗi memory **một dòng**. Nội dung nằm ở file riêng, không viết vào đây.
> Agent đọc file này ở **Phase 0 mọi buổi học**.
>
> Khi nào ghi memory mới (xem AGENTS.md § Memory):
> - cùng một lỗi lặp ≥ 2 lần
> - user nói rõ sở thích cách học
> - phát hiện quy luật về learner (nhớ tốt/kém dạng từ nào)
>
> Memory là **rule hành động được**, không phải nội dung bài học. Khuôn:
